# Fortune in a Pot

A one-line houseplant fortune for the make.fun bounty **Fortune in a Pot** — a warm, funny prediction for a houseplant sitting on the windowsill, written to be read aloud like a real fortune.

## Run

```sh
python3 main.py
```

Writes a single fortune line (no trailing newline) to `/output/entry.txt`
— or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
Python 3 standard library only, no network access.
